Notes:
  • Super = Windows/Super key  |  LMB = Left Mouse Button  |  RMB = Right Mouse Button
  • Super + key = primary apps  |  Alt + key = terminal apps  |  Super + Ctrl + key = system config  |  Super + Alt + key = window management
  • Lock screen uses loginctl lock-session (KDE Plasma lock screen)
  • Media keys control MPD via rmpc CLI
